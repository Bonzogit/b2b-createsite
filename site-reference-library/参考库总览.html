后续如何使用

先有基础规划，再选择参考。先按建站Skill的通用框架明确网站目标、页面用途、内容、询盘路径和后台管理项，再选择整站或模块参考，规划不强制固定布局。

  1. 让 Agent 读取统一建站 Skill 和本目录的 design-library.json。
  2. 结合产品与买家任务挑选 2–3 个候选，实际查看选中模板的首页、列表、详情和手机端。
  3. 重新设计适合本品牌的页面，记录参考依据；与近期最多 5 个项目比较主要布局，避免只换颜色。
  4. 把项目设计记录补入共享库，保留历史与来源。不同 Agent 需要访问同一目录或收到同一份文件。
