# 验收与交接

site_package.py 只读文件，不执行网站代码、不联网。退出0仅表示结构检查通过；不能查尽硬编码密钥，也不能证明权限、数据库或 AI 工作。

使用隔离数据验证：
1. 首页、详情、healthz和真实404，源响应含正文。
2. 匿名拒绝后台/草稿/私密附件；改密码、退出、重启不恢复初始账号。
3. 联系配置全站同步，WhatsApp上下文正确，无假号码或访客信息泄漏。
4. 询盘/附件真实保存，去重生效；邮件失败/未配置仍可查看，失败保留表单。
5. 草稿不可见；发布后列表、详情、标题和版本一致；下架不读缓存，发布失败旧站可用。
6. 按下方翻译专项验收，分别记录源码分支、真实引擎、持久缓存与前台行为，不用其中一项代替其他项。
7. 重启、换域名、模拟升级后内容/账号/媒体/附件保留；隔离恢复核对。
8. 电脑/平板/手机实际查看首页、列表、详情、文章及询盘，记录页面、视口、证据与修复结果；长文本、RTL、空列表、缺图可用。手机端主导航隐藏时应有可操作的替代入口。
9. 对照SITE-BRIEF检查逐页内容覆盖及事实来源，确认参考设计与图片已落实。主图和产品细节符合其用途，公开页面没有制作/配置内部说明；缺少资料和缺少素材单独记录。参见 [图片制作与页面验证](visual-production.md)。

## 翻译专项验收

新版项目先通过 translationContract v2 的语言、词汇库、初始中文和核心指纹检查。每种语言的首页、代表详情、文章和询盘应有当前版本审核记录；明显错义、重复、漏译或不合理英文残留不通过。状态 ready 和型号保留只代表调用/保护结果，不代替语言质量验收。

采用隔离测试内容与已授权服务，遵循 [翻译规范](translation.md)：

1. 源码具有同一模块的两种引擎及运行时注入点；Cloudflare 入口实际传入 AI 绑定，Node 入口读取服务端配置。部署脚本不再为单个项目改写翻译代码。
2. 两种能力同时存在时选择 Workers AI；只有外部配置时选 OpenAI 兼容引擎；无配置为 unconfigured。绑定存在但权限失效与缺绑定分开记录；configured=true 不算真实调用通过。
3. Cloudflare 首次切换非源语言，实际 provider 为 workers-ai，记录真实调用与可见译文。固定字典、源文回显或测试替身不能证明 AI 接通。核对除英文外7种目标语言；中文AI测试使用没有初始译文的新内容，不可用方向明确报错。Node 配置完整后同样验证外部引擎，未配置时原文可读。
4. 用品牌、重复型号、尺寸/数字/单位、邮箱、URL和指定译文术语验证实际结果。模拟缺失、重复、损坏与未知占位符，失败不写缓存、不显示标识；抽查真实语言质量。
5. 同一块同语言第二次请求不新增 AI 调用；清浏览器数据、新浏览器和服务重启后仍命中服务端缓存。以调用计数与缓存记录验证，不能仅凭感觉更快。
6. 修改一段源文，只有受影响块重译，未变块复用；修改语境、模型或术语后相应缓存失效。翻译期间修改、下架或请求旧版本，不能写入或展示失效译文；人工译文优先。
7. 快速切换语言时迟到结果不覆盖当前选择；输入、筛选与表单保留；阿拉伯语 lang/RTL 正确。新增文章发布后列表及详情可按需翻译，不要求重新上传 ZIP。
8. 草稿、询盘、私密附件、账号、访客输入不进入翻译请求或公开日志；只允许已发布内容 ID 和有效 blockIds，拒绝任意文本及跨站内容/缓存读取。
9. 并发请求去重、有限并发、长度校验、超时和有限重试生效；持久任务重启后可恢复。服务端站点预算能在调用前停止请求，不能把账户付费计划会返回额度报错当作免费上限。
10. 模拟未授权、站点/供应商额度耗尽、429、超时、空/数量错误输出：状态和原因明确，已有有效译文/原文可读，不转用收费外部引擎。真实 Cloudflare SDK 的错误映射另核验。
11. 部署/发布默认不全站预热；管理员指定一篇与语言只处理该范围。未做稳定语言地址与实际译文 HTML 时不声称完成多语言 SEO。
12. 无翻译配置的干净安装，初始完整中文直接可用，调用计数为0；按全部初始源块核对中文覆盖。8个语言选项正确，其余6种语言保留源文并准确报状态，不把回显存成译文；全中文 ready 与引擎 unconfigured 可以同时成立。
13. 新增文章无中文seed：配置AI后请求中文得到真实译文并持久化，第二次/新浏览器/重启复用；无AI时准确报缺失。静态词典缺键不能截断该链路。新增产品、页面或动态模块按相同方式验证。
14. 修改英文的一段后旧中文seed失效，仅该块补译；其他中文seed仍有效。修改语境也使对应记录失效；版本改变但块未变不失效。预写/人工译文优先于AI缓存；重复初始化和代码升级不覆盖管理员修改或运行数据。
15. 已成功持久化译文后断开AI配置，当前有效初始中文和AI缓存仍可读；缺失或过期块保留源文并报告状态。恢复/更换引擎后按版本规则处理，不能把断开配置算成全站缓存过期。

报告记录 provider/model、真实或模拟、语言方向、调用/缓存变化、实际存储、结果与限制，不提交密钥和私密日志。参考模块的离线测试只验证适配器行为，不能替代以上网站验收：

```text
node --test unified-site-builder/assets/translation/test_engine.mjs unified-site-builder/assets/translation/test_seed.mjs unified-site-builder/assets/translation/test_resolver.mjs
```

真实邮件测试需要目标收件人与授权；供应商接受不等于实收。真实 AI 与模拟测试分开，无外部授权时完成本地测试并标记限制。

交付文档：
- docs/SITE-BRIEF.md：网站目标、买家任务、页面职责、后台管理项、确认事实/假设与待配置服务，对照site-foundation.md。
- docs/README.zh-CN.md：安装、入口、初始化账号、日常使用。
- docs/CONFIGURATION.md：变量/绑定、必须/可选项及未接通服务，不含凭据。
- docs/BACKUP-RESTORE.md：数据和文件边界、一致备份及恢复。
- docs/HANDOFF.md：核心/协议版本、内容来源、路由生成、设计规则、集成状态、更新和回滚。
- docs/API.md：本项目实际接口路径、字段、返回状态、鉴权与兼容映射；遵循 business-contract.md 及邮件/翻译配套协议。
- docs/design-record.json：参考策略、模块来源、品牌适配与视觉核验状态；共享参考库版本与位置记入 HANDOFF。
- docs/DESIGN.md：页面与界面规则、素材用途和实际文件清单，包含真实/概念属性及待补项目。
- docs/TEST-REPORT.md：pass/fail/unverified、实际环境/命令/日期、真实或模拟服务、证据位置和限制。

features是功能声明，不是测试结果；integrations是实际接入状态。打包后干净目录解压安装并启动，不把测试计划标成通过。报告ZIP大小、SHA-256及实际检测范围。

交付结论分别列出包结构、业务运行、外部服务、内容与素材、视觉验收的实际状态。未查看画面或关键素材待补时可交付明确标注的阶段性版本，不得汇总成“完整验收通过”。本仓库的检查器不评判审美，证据文件存在也不能自动证明其内容有效。
