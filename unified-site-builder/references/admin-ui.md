# 后台界面约定

目标是不同网站使用一致的中文管理习惯。默认后台地址 /admin/，登录后采用左侧导航、顶部站点名和“查看网站”入口、右侧工作区的布局；手机端导航折叠。后台采用清晰、克制的统一界面，不跟随前台换品牌主题。已有验证过的后台组件优先复用；这些约定不等于提供现成组件代码。

## 导航与模块

保持下列顺序与命名，未涉及业务的模块隐藏，不能保留无效入口。产品与服务名称随业务二选一。

| 一级入口 | 常用内容 |
|---|---|
| 概览 | 待处理询盘、草稿、邮件与翻译接入状态，数值来自真实数据 |
| 产品 / 服务 | 内容、分类、排序、规格或服务字段 |
| 页面 | 首页和业务页面的可编辑内容、导航；按本项目实际实现的模块编辑，不承诺通用拖拽器 |
| 文章 | 草稿、已发布、编辑、预览、发布、下架 |
| 媒体 | 公开图片与文件；询盘私密附件留在询盘详情内鉴权查看 |
| 询盘 | 列表、详情、跟进备注、筛选、导出与邮件状态 |
| 翻译 | 8种语言、初始/人工/AI译文来源、当前/缺失/过期块、缓存/任务状态、错误和指定内容的人工触发 |
| 设置 | 网站信息、联系方式、邮件通知、语言与翻译配置、账户与安全 |

## 一致操作

- 保存、预览、发布和下架含义固定。保存草稿不公开，预览草稿需鉴权；发布失败不能显示成功或破坏旧版本。
- 列表具备清楚的加载、空内容和错误状态，编辑页提示未保存修改；删除和不可逆动作按产品需求提供相应保护。
- 联系方式统一编辑一次，所有前台入口同步。邮件后台按 resend-email.md 的字段与验证流程实现。
- 翻译分别展示引擎接入状态和本次内容译文覆盖；未接AI也能有完整初始中文，不能因此把中文标成不可用。代码升级不覆盖管理员修改，详情见 translation.md。
- 接入状态明确区分未配置、已配置、测试中和失败；发信状态与询盘状态分开，服务商接受邮件不显示成已收件。
- 不以 localStorage 保存后台业务数据充当跨设备后台；演示数据仅用于明确标记的预览环境。
- 功能测试遵循 acceptance.md，交接附真实后台入口和实际画面。前台可变化，后台核心操作和接口语义保持一致。

## 后台翻译操作

按 [后台翻译任务](translation-admin.md)接入一键翻译所选/全部语言、前台展示语言与文章自动翻译开关。文章列表提供一键入口；翻译页选择内容和目标语言，显示各语言真实块进度、原因码及失败重试。保存成功与翻译完成分别提示，生成完成标为“待校对”，不冒充语义审核。隐藏语言不删除缓存；默认目标语言与展示语言独立。
