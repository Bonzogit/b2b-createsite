# 跨平台交接

## 入口与能力边界

公开仓库包含 README.md、AGENT_ENTRY.md、unified-site-builder/ 及维护工具；不附固定参考库。完整包从 AGENT_ENTRY.md 进入，单独安装从 SKILL.md 进入，按本次任务加载文档。agents/openai.yaml 只适用于支持该格式的平台，不是其他平台的运行依赖。

仅安装或学习时说明实际读取版本、资源和宿主能力，不创建网站。执行建站需文件修改、运行与实际预览能力；缺项清楚标记，继续可完成部分。不要写死作者机器路径或读取无授权项目。

## 延续项目

先读实际代码、site.contract.json 和 docs/HANDOFF.md。沿用已确认产品、品牌、部署目标及安全可用的授权；只有实际缺项才询问。保护账号、数据库、附件、文章、域名与已有设计。未知事实留作待配置，不编造。

HANDOFF 记录 skillVersion、contractVersion、runtime、公共核心版本、当前项目版本和研究记录位置。旧项目已有参考来源与历史保持原样；不因 Skill 去掉预装目录就删除客户项目证据。规范更新不自动迁移旧工程或升级其数据库。

设计研究按 style-selection.md 从本次资料和实际问题出发，保留来源与日期；不同 Agent 不会自动同步项目历史。更换执行者须核对真实实现及当前证据，不把旧 pass 当作本次验证。

## 交付状态

分别说明实现、外部服务、实际部署、内容素材和视觉/交互状态。离线工具只能证明其声明的检查范围；未看画面不报告视觉通过。翻译、邮件和部署沿用对应规范与授权，不在交接文件写凭据。ZIP 是快照，不会自动同步线上数据。
