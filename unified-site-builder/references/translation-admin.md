# 后台翻译、语言展示与文章自动翻译

适用于新建网站及旧工程升级。复用已有公共引擎、术语表、resolver、源块身份与持久译文，不为后台另建翻译供应商。默认英文源内容、完整初始中文；其他目标语言仍可按需补译。用户要求初始化全部语言时，可在建站阶段预生成并逐项校对，不能将语言入口视为译文完成。

## 管理员操作

- 一键翻译所选语言或全部目标语言；“全部”是 en 以外的 zh/es/ar/ru/fr/de/pt 七种，不包括源语言。
- 独立设置前台展示语言；默认八种，必须保留源语言。隐藏语言不删除其译文，也不影响管理员预译，重新展示时直接复用。
- 文章保存、更新、发布后自动翻译，可关闭或选择默认目标语言。新工程默认开启并选择七种目标语言；低预算网站可仅选中文。保存和发布不等待引擎，成功提示与各语言完成状态分开。
- 任务逐语言显示真实已处理块数/总块数、等待额度、重试、失败和取消；可重试失败语言。生成完成显示“待校对”，不是准确率认证。
- 人工校对继续使用已有翻译编辑入口，当前有效人工译文优先且不会被 AI 覆盖；原文变化使对应旧译文失效。

展示语言不是引擎能力声明。前台 SSR 菜单及公开 GET /api/v1/languages 读取 displayLanguages；自定义前台必须接同一接口。公开解析拒绝隐藏语言，直接页面请求隐藏语言回到源语言。接口和菜单保留源块编号、精确来源检查及 RTL 行为。

## 服务端数据和接口

settings 保存 displayLanguages、translationTargets、autoTranslateArticles。translationJobs 每语言一条，记录 contentId、revision、targetLanguage、blockIds、completed、total、status、attempts、nextRunAt、租约及安全原因码，不记录密钥。已完成块也包括人工、种子和缓存命中，因此任务进度不等于引擎调用数。

| 接口 | 行为 |
|---|---|
| GET/PUT /api/v1/admin/translation-settings | 查询及修改设置；目标语言不含源语言，列表非空且无未知语言 |
| GET/POST /api/v1/admin/translation-jobs | 查进度；以 contentId 和 targetLanguages 创建，省略目标时用后台默认选择，返回 202 |
| POST /api/v1/admin/translation-jobs/:id/retry | 针对最新源版本重试该语言 |

上述接口沿用管理员登录、精确来源和 CSRF。自动文章任务与保存共用事务。重复活跃任务合并；连续保存取消旧版本，最新任务复用未变块译文。删除、下架取消旧任务。执行前后再次校验当前版本，旧结果不得写入新源文。

公开 resolver 仅接受已发布内容。后台使用独立私有适配器预译管理员文章草稿的标题、摘要、正文等未来公开字段，不改变草稿公开状态；不发送询盘、附件、账号、访客输入及未授权私人资料。私有适配器不得暴露成公开草稿翻译入口。

## 队列和持久译文

任务使用 assets/runtime/lib/translation-jobs.mjs，共用 app.mjs 的 resolver。每次处理一个块，服务端串行调度，有限重试；引擎未配置/鉴权/无效输出等终止并供人工重试，额度不足等待下个 UTC 日；部署时仍须核对供应商真实额度。默认每日 500 次站点调用保护保留，不等于 500 篇文章或 Cloudflare 免费配额。

Node：任务随 site.json 存在 DATA_DIR，进程计时器只唤醒；启动恢复持久记录及过期租约。Worker：任务随站点 SQLite Durable Object 保存，由 Alarm 唤醒；原 SITE 绑定、对象类/名字和迁移保留。无需增加 Cloudflare Queues。译文保存在原持久存储，是按内容、语言和源摘要关联的记录；不是修改 ZIP 中的源文件，也不是通用词汇库。初始译文文件仅供首次幂等导入。

访客仍可对已发布内容缺失译文触发原按需解析；后台预译尽量让访客直接读缓存。本版持久任务用于管理员操作及自动文章流程，不宣称已将所有访客请求改成异步队列，也未新增后台术语表编辑器或跨站翻译记忆库。

## 旧网站升级与验收

安装翻译核心不会自动添加后台 UI、任务和调度器。旧工程应检查实际文章保存/发布路由、前台菜单、存储和运行入口，接入共享任务模块及接口，保留原译文、内容、账号和存储；缺失设置可使用兼容默认值。关闭页面、重启、连续改文和缓存命中均须实测。

scripts/test_translation_jobs.mjs 验证共享业务及任务状态；scripts/test_worker_translation_jobs.mjs 用持久 SQLite 和 Alarm 测试适配器重建恢复。测试引擎为替身，只证明调用流程，真实引擎授权、语言方向、语义质量及云端运行另验收，见 acceptance.md。
