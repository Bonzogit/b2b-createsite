# 按需翻译

默认源语言 en，支持 en、zh、es、ar、ru，用户可调整。只维护源文；已有人工语言版本导入时保留关联与版本。
选择语言 → 查询当前版本 → 缺失部分入队 → 显示并持久化 → 后续访问复用。部署/发布不自动全站预热；管理员可主动指定一篇内容及语言，不阻塞原文发布。
优先级：有效人工译文 > 有效缓存 > AI。固定界面词典可保留；正文按语义块和必要语境翻译，不逐词替换。保护品牌、型号、数字、单位、邮箱、网址；正确 lang 和 RTL。

POST /api/v1/translations/resolve 接收 {contentId,revision,targetLanguage} 及可选 blockIds，服务端读取该已发布内容，禁止任意文本滥用公共 AI 额度。旧 DOM 模板接入必须核对文字来自本站公开内容。
返回 {ok:true,data:{status,sourceLanguage,targetLanguage,revision,blocks,retryAfterMs}}；状态 ready/partial/pending/unconfigured/failed。鉴权与校验错误用正确错误 HTTP 状态。前台提示简短，后台有原因和任务状态。

缓存键含站点、源/目标语言、内容块摘要、语境、引擎/提示词版本与术语表版本。修改只重算受影响块；下架停止公开复用。并发、超时、有限重试、去重和站点额度受控。失败不覆盖有效缓存。
快速切换时检查当前语言和内容版本，迟到结果不覆盖；不替换访客输入、不丢筛选条件。译文服务器持久化，重启/新浏览器仍可复用；浏览器只加速与存偏好。
Cloudflare 优先用已授权 Workers AI；Node 用配置的服务端引擎或鉴权服务。执行时查官方支持语言/模型/调用/配额。未配置明确显示状态，模拟测试与真实引擎分开报告；免费额度耗尽不自动购买。
共享引擎与经审核的通用术语表可行，各站完整内容/缓存隔离。草稿、询盘、附件、账号和访客输入不发送翻译。
默认不生成大量语言 HTML。客户端切换不等于多语言 SEO；需要独立语言收录时另实现稳定语言地址和实际译文 HTML，验证后才设置 hreflang。
