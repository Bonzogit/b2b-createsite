统一网站建站 Skill 1.6.4

完整仓库从 AGENT_ENTRY.md 进入；单独安装从 SKILL.md 进入，按任务读取相关规范。参考库独立维护，完整仓库保留同级 site-reference-library；空白 assets/design-library.json 不是实际参考库。

新建流程：内容规划 → 参考设计和实际素材 → 样板与全站 → 功能、服务及画面验收 → 打包/指定部署。
已有网站只修改请求范围，保留数据、账号和域名；不重做整站或另造部署。
完整网站默认两个独立 ZIP，共用代码并适配平台；实际部署默认沿用用户 Ubuntu 工作台。只要一个平台或只做修复时按实际范围交付。
新工程默认 Hy-MT2，密钥由服务端注入；其他引擎明确选择。默认英文、完整中文及8语言选项，其余语言和新增/改文缺失中文按需翻译，人工译文与有效缓存优先。混排正文不得因出现汉字而整段跳过。
邮件检查复用已授权测试地址及安全凭据，不改变业务通知收件人；服务商投递与网站询盘/通知流程分别验证。

Python 3.11+，结构检查不联网或执行网站：
python <skill>/scripts/site_package.py check <project>
python <skill>/scripts/site_package.py pack <project> --output <项目外>/<项目>-server.zip
node --test <skill>/assets/translation/test_engine.mjs <skill>/assets/translation/test_hymt.mjs <skill>/assets/translation/test_seed.mjs <skill>/assets/translation/test_resolver.mjs

结构、业务、外部服务、素材和视觉分别报告。具体历史结果见完整仓库 VALIDATION.md；Skill 更新不自动改变已部署网站。维护更新需验证、同步 GitHub 并保留固定版本分支。

后台翻译：读取 references/translation-admin.md；支持一键全部/所选语言、展示语言设置、文章保存后自动翻译及持久进度。生成完成仍需校对；旧网站须单独升级接线。
